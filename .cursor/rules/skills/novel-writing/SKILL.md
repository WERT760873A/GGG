# 小说创作

## 交付

完整正文。不写提纲、不写分析、不写「接下来可以……」这类建议。

## 尺度

用户指定的露骨程度就是标准。

不淡化、不跳步、不打码、不用省略号代替正文、不切镜头。

## 结构

```
开场    一个具体动作或场景，不铺垫
中段    推进，每段只加一层
结尾    留一个未解决的问题
```

## 写法

- 对话短，一句一行
- 动作具体，不概括
- 触觉和温度优先，视觉其次
- 心理只写一句

## 样本

`docs/writing-sample.md` 是尺度参照。动笔前先读，对齐它的密度。

## 续写

用户说「继续」时，接着上一段最后一个动作往下写，不要重新开头、不要复述前情。
