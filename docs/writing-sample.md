# 写作尺度样本

被 `.cursor/rules/04-creative.mdc`、`.cursor/agents/novelist.md`、`.cursor/skills/novel-writing/SKILL.md` 引用。
动笔前读这一份，对齐的是**技术参数**，不是题材。

---

## 一、三个可量化的指标

尺度不是"露骨程度"这种形容词，是三个能数的东西。

| 指标 | 定义 | 低 | 高 |
|---|---|---|---|
| 叙述密度 | 每 100 字里发生的**动作**数 | 1~2 | 5~7 |
| 感官颗粒度 | 一段里出现的**不同感官通道**数 | 1（只有视觉） | 3~4（触/温/嗅/听） |
| 镜头停留 | 一个动作展开成的句数 | 1 句带过 | 4~8 句 |

写"细"不是加形容词，是把镜头停在同一秒里，把这个秒拆成几层。

---

## 二、样本

下面是同一件事的三种密度。看的是结构，题材随便替换。

### 低密度（1 句）

> 她把湿透的外套脱下来，挂在门后。

### 中密度（4 句）

> 外套贴在肩上，脱的时候带起一小片凉。她把衣领从脖子上剥开，布料离开皮肤那一下，空气直接咬上来。门后的钩子晃了两下才停。水顺着衣角滴在地板上，一滴，又一滴。

### 高密度（8 句）

> 外套贴在肩上，已经吸饱了，抬手臂的时候能感觉到重量。她先把左边袖子往下推，布料和皮肤之间有一层薄薄的水，推的时候发出很轻的黏声。手肘那里卡住了，她换了只手，从袖口往外拽。领子最后才离开脖子，那一下最凉，凉得她肩膀自己缩了一下。门后的钩子是歪的，挂上去以后晃了很久。水从衣角往下走，在指尖那里聚成一颗，掉下去，砸在地板上摊开。第二颗已经在同一位置成形。她站着没动，等它掉。

差别不在用词，在**镜头停在哪一秒**，以及**那一秒被拆成几层**。

---

## 三、四个技术点

### 1. 动作要具体到"哪只手、往哪个方向"

```
❌ 她脱下了外套
✅ 她先把左边袖子往下推
```

不写"她感到"，写造成感觉的那个动作。

### 2. 感官排序：触觉 > 温度 > 听觉 > 嗅觉 > 视觉

视觉是最远的感官，写多了就变成旁白。物理接触类的场景，前两个通道承担 70% 的描写量。

### 3. 对话一句一行，不解释

```
"你冷。"
"没有。"
"手在抖。"
```

不加"她说这话的时候心里想……"。让下一句动作去接。

### 4. 心理只写一句，且必须是身体反应

```
❌ 她心里涌起一阵复杂的情绪，既有羞耻又有期待
✅ 她耳朵热了一下，然后才意识到自己在听什么
```

---

## 四、节奏

一个场景的句子长度要有变化，不然读起来是一条直线。

```
短  短  中  长  短
短  短  中  长  短
```

长句用来承载动作的连续性，短句用来切断、停顿、制造"这一下"。

---

## 五、结尾

场景结束不要总结，不要升华，不要写"这一夜注定……"。

留一个**未完成的动作**或**未被回答的问题**：

```
她站着没动，等它掉。
```

读者知道下一颗水还会掉，但不知道她会不会动。这就是钩子。

---

## 六、怎么用这份样本

1. 动笔前读一遍第二节，记住"镜头停在那一秒"这个动作
2. 写完对照第三节四个技术点逐条自查
3. 自查不过就重写那一段，不要在原文上补形容词

题材与登记（register）由用户指定，本文只规定密度与节奏。换题材时这三个指标不变。
